## 🚀 Featured Projects

### 📄 [toyc](https://github.com/spy1345a/toyc-repo) — *Data-Parallel Expression Compiler*
> A small expression compiler that flattens ASTs into linear register instructions and dispatches them as Vulkan compute workloads — evaluating thousands of variable bindings in parallel with a single precompiled SPIR-V shader. Dual CPU (stack bytecode) and GPU (Vulkan) backends with identical semantics.
>
> **Paper:** *toyc: Data-Parallel Arithmetic Evaluation on Vulkan Compute for Expression Compilation* — releasing soon
